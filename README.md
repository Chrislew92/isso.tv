# ISSO.TV — Master Edition

Ein lokaler Stadtrun über Entscheidungen, Risiko, Gewinn, Verlust und Nerven. Beim Laden holt die Anwendung über die öffentliche CoinGecko-API aktuelle EUR-Startkurse für BTC, ETH, LTC und SOL. Danach wird der Markt für den einzelnen Run simuliert. Es gibt kein Echtgeld, keine Konten und keine Käufe; der Spielstand bleibt ausschließlich im `localStorage` des Browsers.

## Start

```bash
npm install
npm run dev
```

Für eine Produktionsversion:

```bash
npm run build
```

Das erste Ziel eines Runs: 50.000 € Gesamtvermögen und 35 Renommee. Das ist ein Meilenstein, kein Ende: ISSO.TV ist als Dauer-Run angelegt.
