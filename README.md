# ISSO.TV — 353L.EXE

Highroller-RPG in einer einzigen `index.html`. Keine Frameworks, keine
externen Dateien, kein Build. Datei im Browser oeffnen, fertig.

Zugangscode wird nicht im Klartext gespeichert (gesalzener SHA-256).
Achtung: Das ist ein Vorhang, kein Schloss — wer den Quelltext liest,
kann die Sperre umgehen. Echter Schutz braucht .htaccess oder Cloudflare Access.

## Dateien
- `index.html`  — das komplette Spiel
- `353L.cs`     — Quelltext des Desktop-Starters (353L.exe)
- `IDEEN.md`    — Ideenspeicher, roh
- `README.md`   — diese Datei
